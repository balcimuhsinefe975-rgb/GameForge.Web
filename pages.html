GameForge Kullanım Kılavuzu

Kurulum

GameForge'u indirdikten sonra çalıştırın. İlk açılışta animasyonlu intro gösterilir. Yönetici olarak çalıştırmanız önerilir (tüm tweak'ler için). 

pip install psutil pillow requests pynput pystray nvidia-ml-py3
python GameForge.py

Hızlı Başlangıç

  1. Uygulamayı aç
  2. Dashboard'dan mod seç (Güvenli / Dengeli / Agresif)
  3. "Aktif Modu Uygula" butonuna bas
  4. Kütüphane'den oyun tara ve seç
  5. Launcher'dan başlat — çıkışta otomatik geri alınır

SSS

Sıkça sorulan sorular ana sayfada bulunabilir.

Sorun Giderme

Log dosyası: %LOCALAPPDATA%\GameForge\gameforge.log

Eklentiler

%LOCALAPPDATA%\GameForge\plugins klasörüne .py dosyaları koyun. Otomatik yüklenir.

Kısayollar

  • Ctrl+Shift+F9 — Overlay aç/kapat
  • Ctrl+Shift+F10 — Dashboard'a dön
  • Ctrl+Shift+F11 — Forge Modu
